# reborn-everyday.github.io

Yeonjung Hong's personal portfolio site. Plain static HTML/CSS, no build step,
no Jekyll — GitHub Pages serves whatever is committed to `main` at the repo
root as-is. That means anything committed here is publicly servable; keep
private/rough content out of git (see below).

## Pages
- `index.html` — home
- `wellness.html` — yoga teaching, mindfulness, workplace wellness
- `ai-career.html` — AI/product work
- `art.html` — art
- `styles.css` — shared "Organic" design-system tokens and component classes (see the file header comment). Retune the look here; page-specific `<style>` blocks in each HTML file hold layout/overrides scoped to that page.

## Drafts
`NOTES.md` at the repo root is gitignored and local-only — it's the user's
freeform scratchpad for draft ideas about upcoming page content/design.
Check it at the start of a session if it exists, and treat it as informal
context and a starting point, not a finished spec.
